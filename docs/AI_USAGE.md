# AI usage

This repository was built with Claude Code driving the work from `SPECS.md` and `CLAUDE.md`.

- The AI wrote code, scripts, IaC and docs; a human defined the specs and rules.
- Output was reviewed through the toolchain, not by trust: strict TypeScript, lint, unit and contract tests against real Postgres/Redis, Playwright against the real console, a load test with threshold assertions, and CDK synth/deploy against a real AWS account.
- Proof artifacts under `proof/` are generated by scripts so they can be reproduced.
